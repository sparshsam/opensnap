# Security Policy

## Reporting a vulnerability

OpenSnap is a desktop screenshot utility with no network features beyond checking for updates via the public GitHub API. It does not upload, transmit, or store any user data remotely.

If you discover a security concern, please report it privately — do not open a public issue.

Use GitHub's private vulnerability reporting:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Complete the form with as much detail as you can provide.

Include: a clear description of the issue, reproduction steps, the OpenSnap version and operating system, and the expected impact.
